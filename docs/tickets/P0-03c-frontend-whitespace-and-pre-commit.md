Split from [P0-03](./P0-03-frontend-quality-gates.md). The scope item came from P0-02's review (the
pre-commit whitespace/EOF hooks were scoped to `backend/` because the frontend wasn't clean).

## Scope

- Extend the `end-of-file-fixer` and `trailing-whitespace` hooks in `.pre-commit-config.yaml` to `frontend/`.
- Run them once and commit the result. Nothing else changes.

## Acceptance criteria

1. `pre-commit run --all-files` passes on the PR head with `frontend/` in scope.
2. The change is whitespace-only: `git diff -w --ignore-blank-lines origin/main...HEAD -- frontend` is empty
   (transcript).
3. `npm run lint`, `npm run typecheck` and `npm run build` still pass (CI).
4. Every changed line that sits inside a JS/TS string or template literal is listed in the PR with why the
   whitespace there doesn't matter at runtime (found by scanning the pre-change files with the TypeScript
   parser). A literal whose trailing whitespace is significant is excluded from the hooks rather than
   changed.
5. The `files:` patterns for the two hooks are the only lines changed in `.pre-commit-config.yaml` besides
   the comment that said P0-03c would extend them.

## Frame notes (filled by the agent in step 1)

- Criteria added or sharpened: AC4 (missed case): `git diff -w` hides whitespace removed *inside* a string or
  template literal, which changes the runtime value. A trial run found 7 such lines in 3 files on
  `origin/main` 1deb22a: `src/Layout.jsx` (a Tailwind `className` template; class lists split on any
  whitespace), `src/components/NotificationHelper.jsx` (HTML email markup; HTML collapses whitespace) and
  `src/pages/Concierge.jsx` (an LLM prompt; trailing spaces before a newline carry no meaning). None is
  significant, so none is excluded. AC5 keeps the config change minimal.
- Criteria loosened (with reason; also listed in the inbox): none.
- Decisions taken (with basis: ticket / ADR / default / autonomous): the hooks run on all of `frontend/`
  (ticket), including legacy Base44 files and `base44/*.jsonc`; no `--markdown-linebreak-ext` argument,
  because no Markdown file under `frontend/` has trailing whitespace today (default: smallest change).
- Size: 2 config lines plus ~98 whitespace-only files (generated by the hooks); no split.
